# Тестовые матрицы

Формат: одна строка файла — одна строка матрицы, элементы через пробел.

| Файл | Размер | Описание |
|---|---|---|
| `square2_a.txt`, `square2_b.txt` | 2×2 | A·B = [[19, 22], [43, 50]] (чётное M) |
| `square3_a.txt`, `square3_b.txt` | 3×3 | A·B = [[30, 24, 18], [84, 69, 54], [138, 114, 90]] (нечётное M) |
| `square5_a.txt`, `square5_b.txt` | 5×5 | произвольные числа, удобно сравнивать алгоритмы между собой |
| `identity3.txt` | 3×3 | единичная матрица |
| `zero3.txt` | 3×3 | нулевая матрица |
| `negative3.txt` | 3×3 | отрицательные элементы |
| `rect2x3.txt`, `rect3x2.txt` | 2×3, 3×2 | A·B = [[58, 64], [139, 154]] |
| `rect2x4.txt` | 2×4 | например, `rect3x2.txt` · `rect2x4.txt` → 3×4 |
| `row4.txt`, `column4.txt` | 1×4, 4×1 | строка·столбец = [[30]], столбец·строка → 4×4 |
| `invalid_rows.txt` | — | строки разной длины, должна быть ошибка загрузки |
| `invalid_number.txt` | — | нечисловой элемент, должна быть ошибка загрузки |

Несовместимые пары для проверки ошибки умножения: `rect2x3.txt` · `rect2x4.txt`, `square2_a.txt` · `square3_a.txt`.
