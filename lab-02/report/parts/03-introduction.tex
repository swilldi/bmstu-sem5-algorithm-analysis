\ssr{ВВЕДЕНИЕ}

Цель работы~--- выполнить сравнительный анализ алгоритмов умножения матриц по трудоёмкости.

Задачи работы:
\begin{enumerate}
	\item описать решаемую согласно варианту задачу;
	\item разработать алгоритмы решения задачи согласно варианту: стандартный алгоритм умножения матриц, алгоритм Винограда и три оптимизированные версии алгоритма Винограда по варианту;
	\item описать разработанные алгоритмы схемами алгоритмов;
	\item описать требования к программному обеспечению;
	\item описать средства реализации алгоритмов;
	\item реализовать разработанные алгоритмы;
	\item выполнить тестирование реализации алгоритмов;
	\item описать модель вычислений для оценки трудоёмкости алгоритмов и выполнить теоретический расчёт трудоёмкости;
	\item описать инструменты замера процессорного времени выполнения реализаций алгоритмов;
	\item выполнить массированные замеры процессорного времени выполнения реализаций алгоритмов в зависимости от линейного размера квадратных матриц, отдельно для чётных и нечётных размеров;
	\item выполнить сравнительный анализ алгоритмов по трудоёмкости и по данным выполненных замеров.
\end{enumerate}
