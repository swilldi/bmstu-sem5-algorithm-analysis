\section{Технологическая часть}

\subsection{Средства реализации}
В качестве языка программирования был выбран Swift версии~6.4~\cite{swift-book}, так как он является языком со статической типизацией и основным языком разработки для операционной системы macOS, на которой выполнялась лабораторная работа. Сборка выполнялась с помощью Swift Package Manager.

При реализации использовались следующие средства:
\begin{itemize}
	\item тип \texttt{Array} стандартной библиотеки Swift~--- матрица представлена как массив строк \texttt{[[Int]]}, вспомогательные массивы $mulH$ и $mulV$~--- как \texttt{[Int]};
	\item для замера процессорного времени~--- функция \texttt{clock\_gettime\_nsec\_np} системной библиотеки macOS~\cite{clock-gettime} (подробнее в разделе~\ref{sec:time-tools});
	\item библиотека Swift Testing~\cite{swift-testing}~--- для модульного тестирования реализаций.
\end{itemize}
